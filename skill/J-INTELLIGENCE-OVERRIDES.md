# J Intelligence × DESIGN.md (Superhuman-inspired)

> **วิธีใช้:** ใช้ `DESIGN.md` ในโฟลเดอร์นี้เป็นแนว layout, จังหวะหน้า และรูปทรง component ส่วนสี ฟอนต์ และกฎเนื้อหา ให้ใช้ตามไฟล์นี้ ถ้าขัดกัน ไฟล์นี้ชนะ
> **ที่มา:** DESIGN.md มาจาก VoltAgent/awesome-design-md (MIT, ดู LICENSE-awesome-design-md) และเป็นการวิเคราะห์สไตล์ ไม่ใช่ไฟล์ของแบรนด์จริง

## สิ่งที่หยิบมาจาก DESIGN.md

- **ระบบพื้นหลัง 3 ช่วง:** hero มืด → เนื้อหาพื้นขาว → แถบปิดท้ายสีเข้ม
- **ฉากหลังของ hero:** ไล่สีม่วงไปฟ้าแบบท้องฟ้าตอนพลบค่ำ และมี "portrait" ครึ่งจอด้านขวา
- **ปุ่มเรียกให้ทำ (CTA):** มีปุ่มเดียวต่อหนึ่งแถบ ปุ่ม pill ใช้เฉพาะใน hero ส่วนเนื้อหาใช้ปุ่มสี่เหลี่ยมมุมมน 8px
- **การ์ด:** มุมมน 12px
- **ตัวหนังสือ:** ตัวใหญ่หัวข้อตั้งบรรทัดแน่น และใช้น้ำหนักกลาง ๆ (460/540) สำหรับตัวอักษรละติน
- **ส่วนเลือกบริการ:** ใช้ pill tabs
- **แพ็กเกจแนะนำ:** การ์ดสลับเป็นสีเข้ม

## สิ่งที่แปลงเป็นของ J Intelligence

| DESIGN.md | J Intelligence |
|---|---|
| Indigo navy `#1b1938` (hero, featured) | `#07070F` |
| Violet-sky backdrop | radial ม่วง `#8B5CF6` + ฟ้า `#38BDF8` บน `#07070F` |
| Pale violet pill `#c9b4fa` | gradient `#8B5CF6→#38BDF8` + ตัวหนังสือ `#07070F` |
| Canvas `#ffffff` / canvas-soft | `#ffffff` / `color-mix(#8B5CF6 4%, #fff)` |
| Ink `#292827` | `#07070F` (mute = `#07070F` 62% ≈ 5.9:1 บนขาว) |

| Super Sans VF 460/540 | Plus Jakarta Sans 460/540 สำหรับละติน และ Prompt 400/500/600 สำหรับไทย |
| Half-bleed portrait (รูปคน) | "portrait" ของแชทตอนตีสอง วาดด้วยโค้ด ไม่ใช้รูปคนจริง |
| line-height 0.96 | ภาษาไทยใช้ 1.15 เพราะสระบนและวรรณยุกต์จะถูกตัด |

## กฎที่ห้ามละเมิด

- **สี:** ใช้แค่ `#07070F`, `#8B5CF6`, `#38BDF8` และขาว
- **Contrast บนพื้นขาว:**
  - ห้ามใช้ตัวหนังสือฟ้า `#38BDF8` (2.14:1) และห้ามใช้ gradient text
  - ตัวหนังสือม่วงใช้ได้เฉพาะหัวข้อขนาด 24px ขึ้นไป (4.23:1)
- **ตัวหนังสือบนปุ่ม gradient:** ต้องเป็น `#07070F`
- **เนื้อหา:**
  - ห้ามแต่งตัวเลข, จำนวนลูกค้า หรือรีวิว
  - ห้ามมีเบอร์โทร, LINE ID หรืออีเมล ลิงก์ออกนอกเว็บได้แค่ Fastwork
  - ห้ามใช้โลโก้ของแบรนด์จริง
  - ร้านตัวอย่างต้องติดป้าย "แบรนด์สมมติเพื่อแสดงผลงาน"
- **เครื่องหมายคำพูด:** ใช้ `"` แบบตรง
- **ต้องรองรับ:** `prefers-reduced-motion`, จอ 375px และ 1440px โดยไม่มีสกรอลแนวนอน

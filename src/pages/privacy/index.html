นโยบายความเป็นส่วนตัว

เว็บนี้ไม่ใช้คุกกี้ ไม่ติดตามผู้เข้าชม และไม่มีฟอร์มให้กรอกข้อมูล หน้านี้อธิบายว่ามีข้อมูลอะไรถูกบันทึกบ้าง และผมดูแลข้อมูลของลูกค้าระหว่างทำงานอย่างไร

สรุปสั้นๆ

สิ่งที่เว็บนี้ไม่ทำ

ไม่ใช้คุกกี้และไม่ติดตาม

ไม่มีเครื่องมือวัดสถิติ โฆษณา หรือพิกเซลติดตามใดๆ

ผู้ช่วยในเว็บไม่ส่งข้อความออกไป

ปุ่ม "ถามผู้ช่วย" ตอบจากคำตอบที่เตรียมไว้ในหน้าเว็บ ข้อความที่คุณพิมพ์อยู่ในเครื่องคุณเท่านั้น

ไม่มีฟอร์มเก็บข้อมูล

การติดต่อ จ้างงาน และชำระเงินทั้งหมดทำผ่าน Fastwork

รายละเอียด

1. ข้อมูลที่ถูกบันทึกเมื่อคุณเข้าเว็บ

เว็บนี้ฝากไว้กับ Netlify และ GitHub Pages ผู้ให้บริการทั้งสองอาจบันทึกข้อมูลทางเทคนิคตามปกติของเซิร์ฟเวอร์ เช่น หมายเลข IP ประเภทเบราว์เซอร์ และหน้าที่เปิด เพื่อให้เว็บทำงานได้และป้องกันการโจมตี ผมไม่ได้ใช้ข้อมูลนี้ระบุตัวผู้เข้าชม

บนคอมพิวเตอร์ หน้าแรกโหลดไลบรารีภาพเคลื่อนไหว (three.js) จาก jsDelivr ซึ่งเป็นผู้ให้บริการไฟล์สาธารณะ jsDelivr จึงเห็นหมายเลข IP ของคุณเหมือนการโหลดไฟล์ทั่วไป ถ้าตั้งค่าเครื่องให้ลดการเคลื่อนไหว หรือเปิดบนมือถือ ไฟล์นี้จะไม่ถูกโหลด

2. ลิงก์ไป Fastwork

ปุ่ม "ทักคุยใน Fastwork" พาไปเว็บ Fastwork ซึ่งมีนโยบายความเป็นส่วนตัวของตัวเอง ข้อมูลที่คุณให้ Fastwork อยู่ภายใต้นโยบายนั้น

3. ข้อมูลของลูกค้าระหว่างทำงาน

  • ข้อมูลร้านที่คุณส่งให้ (สินค้า ราคา คำถามที่พบบ่อย รูป) ผมใช้เพื่อทำงานที่จ้างเท่านั้น ไม่นำไปใช้หรือเปิดเผยกับงานอื่น
  • บัญชีบริการ AI โฮสติ้ง และคีย์ต่างๆ สร้างในชื่อคุณ คุณเป็นเจ้าของระบบ 100%
  • ถ้าต้องใช้สิทธิ์แอดมินของ LINE OA หรือเพจ ผมแนะนำวิธีให้สิทธิ์แบบจำกัด และคุณถอนสิทธิ์ได้ทันทีหลังส่งงาน
  • บอทที่ผมทำ ข้อความของลูกค้าคุณจะถูกส่งไปผู้ให้บริการ AI ที่คุณเลือกเพื่อสร้างคำตอบ ผมแจ้งผู้ให้บริการและการตั้งค่าให้ทราบก่อนเริ่มงาน
  • เมื่อจบงาน คุณขอให้ผมลบไฟล์ข้อมูลที่ส่งมาได้ทุกเมื่อ

4. ติดต่อเรื่องข้อมูลส่วนบุคคล

ถ้ามีคำถาม หรือต้องการให้ลบข้อมูล ทักมาที่ โปรไฟล์ Fastwork ของผม (เปิดในแท็บใหม่)

5. การเปลี่ยนแปลงนโยบาย

ถ้าเว็บเพิ่มสิ่งที่เก็บข้อมูล เช่น ฟอร์มติดต่อหรือเครื่องมือวัดสถิติ ผมจะปรับหน้านี้ก่อนเปิดใช้ และแก้วันที่ปรับปรุงล่าสุดด้านบน
